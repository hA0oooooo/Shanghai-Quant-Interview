##### 阅读路径

从量价入门可先读趋势与订单流两篇。一篇在月度尺度检验过去信号与未来收益；一篇在秒级尺度解释已发生的同期价格变化。随后阅读股票预期收益和条件因子两篇，比较同期回归、样本外重建和事前预测之间的信息边界。最后进入配置研究，检查相同或较低的预测误差是否真的导致更合适的风险暴露
