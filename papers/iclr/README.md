##### ICLR · 金融市场生成与配置

生成金融数据至少有三种用途。形态生成用新序列扩充训练集；交互式仿真要在订单改变后更新市场；条件收益生成将分布估计作为组合决策的输入。三篇均可从各自 ICLR 主会正式论文集核查，评价标准取决于生成器的用途

| 研究任务 | 输入与输出 | 检验重点 |
| --- | --- | --- |
| [形态分段与扩散生成](金融时序的形态分段与扩散生成.md) | 原始价格路径 → 形态类别、实例与时间转移 → 合成序列 | 加入训练后，未见真实数据上的预测误差 |
| [订单生成与交互式市场仿真](订单生成与交互式市场仿真.md) | 订单与批次条件 → 新订单 → 撮合后状态 | 市场统计规律、条件场景及外部订单的影响 |
| [条件扩散与组合配置](条件扩散与组合配置.md) | 市场及个股信息 → 收益轨迹与风险估计 → 持仓 | 组合表现与收益路径预测误差分别报告 |
