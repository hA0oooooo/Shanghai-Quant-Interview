##### 金融预测中的统计学习

面板预测的第一步是定义在时点 $t$ 可见的信息，以及模型要估计未来收益分布的哪个量。训练目标改变之后，模型结构、数据切分和评分的解释也会改变。下列四组笔记按这一依赖关系排列

##### 预测目标与评分

| 主题 | 核心关系 |
| --- | --- |
| [条件统计量与损失函数](objectives/条件统计量与损失函数.md) | 平方、绝对和分位数损失分别选择条件分布的不同统计量 |
| [样本权重与零基准评分](objectives/样本权重与零基准评分.md) | 样本权重改变训练分布，评分分母决定不同区间如何合并 |
| [截面排序与幅度校准](objectives/截面排序与幅度校准.md) | 排序可能不变，数值误差、风险暴露和仓位仍会改变 |

##### 估计器与正则化

| 主题 | 核心关系 |
| --- | --- |
| [线性回归与收缩估计](estimators/线性回归与收缩估计.md) | 弱奇异方向的系数对样本扰动敏感，正则化抑制这些方向 |
| [决策树与梯度提升](estimators/决策树与梯度提升.md) | 用阈值与交互拟合非线性，以样本外结果决定叶子容量 |
| [协方差收缩与主成分](estimators/协方差收缩与主成分.md) | 收缩改善协方差条件数，截断主成分改变输入保留的信息 |

##### 时间验证与分布变化

| 主题 | 核心关系 |
| --- | --- |
| [时点数据与标签成熟](validation/时点数据与标签成熟.md) | 按决策时刻复原数据版本与当时可训练的标签 |
| [滚动验证与模型选择](validation/滚动验证与模型选择.md) | 外层窗口衡量整套模型选择过程的表现 |
| [分布漂移与归一化](validation/分布漂移与归一化.md) | 分清输入分布、资产构成和条件关系哪一项发生变化 |

##### 组合预测与归因

| 主题 | 核心关系 |
| --- | --- |
| [误差相关与模型融合](combination/误差相关与模型融合.md) | 根据误差协方差理解互补，按过去窗口估计融合参数 |
| [特征重要性与增量信息](combination/特征重要性与增量信息.md) | 扰动固定模型与删列重训估计不同反事实 |
| [分位数与预测区间](combination/分位数与预测区间.md) | 在总体覆盖之外衡量区间宽度及高波动时段的可靠性 |

若预测对象是截面资产，排序增量可以接到[量价因子](../price-volume-factors/README.md)的中性化、换手和净收益分析。若希望同时利用历史轨迹与同期关系，可以从[深度学习](../deep-learning/README.md)的面板时间轴与截面轴继续阅读
