##### 线性模型的可辨识性

把资产特征组成矩阵 $X$，预测为 $X\beta$。一列成交额恰好等于另一列的两倍时，许多不同系数能产生完全一样的拟合值，单个系数无法从这份数据唯一反推。两列高度相关而非完全相同时，训练误差可能平稳，系数却会对一个新时段或很小的噪声剧烈变化

对已中心化的变量，将岭回归写作 $\min_\beta\|y-X\beta\|_2^2+\lambda\|\beta\|_2^2$。若 $X=U\operatorname{diag}(s_j)V^\top$，其系数在第 $j$ 个右奇异方向上为 $s_j(u_j^\top y)/(s_j^2+\lambda)$。相对最小二乘，各方向缩小因子为 $s_j^2/(s_j^2+\lambda)$。若 $s_j=10$ 或 $1$ 且 $\lambda=1$，对应保留约 99% 或 50%，解释了为什么信息薄弱方向被优先压缩 [线性模型与岭回归](https://scikit-learn.org/stable/modules/linear_model.html)

##### 稀疏与稳定是两种目标

Lasso 以 $\ell_1$ 惩罚鼓励系数精确为零；多个高度相关的特征可在不同训练窗口替代彼此，产生不稳定的入选名单。Elastic Net 混合 $\ell_1$ 与 $\ell_2$，兼顾特征筛减与数值稳定。若各列量纲不同，惩罚会隐含偏好大尺度的列；训练期估计缩放参数，截距通常独立处理

在量价面板上，固定线性基线可把非线性模型的收益拆开：先比较原始量价特征与加入滚动特征后的改进，再在相同信息上比较树或网络。否则全量模型优于简单基线的差距同时混有特征扩充和拟合形式变化 [机器学习在实证资产定价中的比较](https://www.nber.org/papers/w25398)

相同的弱特征方向也会使风险估计矩阵难以求逆，见[协方差收缩与主成分](协方差收缩与主成分.md)
