##### 金融面板、序列模型与语言模型

金融面板至少有时间、资产和特征三个维度。模型首先需要明确哪个轴上的对象可以交互，再决定用什么监督学习表示，以及部署时怎样复现训练期的信息集。语言模型通过文本扩充观测维度，其抽取质量与金融预测增量须分别衡量
