##### 量化预测竞赛的任务与方法

相同的金融面板可以用来预测价格方向、相对收益、波动大小或事件反应。目标定义决定输出单位，评估函数决定哪些误差昂贵，数据接口决定预测当时能使用哪些证据。先确定这三件事，再比较特征和模型

| 案例 | 预测对象与指标 | 主要研究问题 |
| --- | --- | --- |
| [XHTH 匿名资产面板](xhth/README.md) | 连续 target，加权零均值 $R^2$ | 共同分量与相对分量、辅助监督、误差幅度校准 |
| [Ubiquant 匿名投资标的](ubiquant/匿名面板与截面相关.md) | 匿名目标，时点内 Pearson 相关再跨时点平均 | 截面排序与数值距离、市场状态与标的覆盖 |
| [Optiver 收盘竞价](optiver-close/收盘竞价与相对收益.md) | 未来 60 秒个股 WAP 相对合成指数的变化，MAE | 竞价失衡、时间界限、模型误差互补 |
| [Optiver 已实现波动率](optiver-volatility/盘口到已实现波动率.md) | 未来窗口内的已实现波动率，RMSPE | 波动聚集、微观噪声、历史市场近邻 |
| [Jane Street 实时预测](jane-street/评分与标签回流.md) | 匿名响应，加权零均值 $R^2$ | 延迟标签、在线状态与逐时回放 |
| [Explaining Markets 财报事件](explaining-markets/财报事件与增量解释力.md) | 季度内事件价格反应的百分位，考察相对盈利意外的增量解释力 | 财报语义、事件时钟、嵌套回归 |

XHTH 和 Explaining Markets 是独立赛事，另外四项为 Kaggle 比赛。各篇把数据规则和观测到的模型表现分别说明。比赛的预测分数必须经过持仓和执行层才能转成收益 [XHTH 官方赛事](https://race.xhth.cn/) · [Explaining Markets 规则](https://portal.explainingmarkets.ai/contest-rules)

##### 跨任务的三个联系

- 当天的其他资产是否可见，决定位于时间轴还是资产轴的聚合是否合法。截面均值、当前盘口和前一日回流标签各有不同的可用时间 [时序与标签表](研究方法/数据到达与标签时钟.md)
- 匿名市场变量可提供共同背景，截面去均值可提取相对目标。能否去掉共同成分，取决于评分是否惩罚共同偏差 [截面评分](ubiquant/匿名面板与截面相关.md) · [分量校准](xhth/预测融合与推理.md)
- 日历、部署算力与成本改变可用的方法集合。训练数据中很有效的联合近邻检索，部署时可能须改成逐时更新的索引 [市场状态检索](optiver-volatility/近邻聚合与时间边界.md) · [公开结果的比较条件](研究方法/误差指标与结果比较.md)
