##### 匿名资产面板的时序预测

2026 年量化交易研究大赛使用匿名资产面板。一个观测由时点、资产标识和数值特征构成，预测接口按时点提供当前出现的资产。训练表另含权重、主目标和辅助响应。数据匿名化保留了可建模的时间和截面结构，同时限制了对具体市场机制的解释 [赛事入口](https://race.xhth.cn/)

##### 从评分到研究设计

加权平方误差同时惩罚共同分量和资产相对分量的预测偏差。可先区分两类误差，再研究怎样构造特征、分配训练权重和检验跨时段增量。本专题的构造算例用于说明机制
